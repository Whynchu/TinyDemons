# TinyDemons

![TinyDemons gameplay screenshot](docs/game-screenshot.png)

TinyDemons is a small isometric action prototype built in Godot. The current project includes a playable room with slime variants, room progression, combat, targeting, health UI, and the supporting artwork source files used to build the scene.

## Project Layout

- `tiny-demons/` - the Godot project
- `Artwork/` - exported and source art files
- `Mockups/` - reference mockups
- `docs/game-screenshot.png` - current in-game screenshot used in this README

## Running The Project

Open `tiny-demons/project.godot` in Godot 4.7 and run the main scene.
