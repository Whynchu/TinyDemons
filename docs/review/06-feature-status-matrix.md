| Optional elemental routes | Partial/planned | Do they add discovery without blocking progress? |
| Keys and switches | Partial/planned | Do they create meaningful room decisions? |
| Carried orb sections | Prototype direction | Is carrying readable, safe from softlocks, and worth the friction? |
| Puzzle variety | Partial/planned | Are puzzles distinct, compact, and replayable? |
| Biome roster | Partial/planned | Does each biome change tactics, not just palette? |
| Gear and stats | Implemented | Is the reward economy deep without becoming grindy? |
| Skill trees | Planned | Do they create meaningful build identity? |
| Touch controls | Implemented and authorable | Are they comfortable on small, low-end phones? |
